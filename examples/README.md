# Examples

Pre-generated output from the builder presets. **Do not edit these by hand**.
they are regenerated by `npm run examples` and any changes will be lost.

Each is a complete, standalone project:

```bash
cd examples/minimal
npm install
npm start
```

| Directory | Preset | Package manager | What it is |
| --- | --- | --- | --- |
| [`minimal/`](minimal/) | `minimal` | npm | One iframe and a URL bar, plain JavaScript with no build step. Read this one first; every other preset is this plus features. |
| [`standard/`](standard/) | `standard` | bun | The recommended setup. TypeScript, Vite and Tailwind on Fastify, with tabs, settings and transport switching. |
| [`everything/`](everything/) | `everything` | bun | Every feature enabled, on Bun with Tailwind. Heavier than you need. |
| [`serverless/`](serverless/) | `serverless` | npm | Scramjet over a Bare server, for serverless hosts that cannot hold a WebSocket open. |
| [`react/`](react/) | `react` | npm | A React shell built with TypeScript and Vite. |
| [`astro-preact/`](astro-preact/) | `astroPreact` | npm | A static Astro frontend with a hydrated Preact proxy island. |

To produce your own combination:

```bash
node builder/cli.js --out ./my-proxy --features tabs,settings,history
```

Or run the documentation site and open its `/build` route.
